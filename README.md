# Експертні системи на базі CLIPS
Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології»

## Автор
- Студентка: Сема Ангеліна
- Група: ІН-31/2

## Структура репозиторію
- `Lab1/` - операції з фактами (assert, retract, facts), deffacts та прості правила
- `Lab2/` - створення шаблонів (deftemplate) та впорядковані факти
- `Lab3/` - формування бази правил (defrule) експертної системи визначення класу пожежі
- `Lab4/` - створення та використання функцій (deffunction)
- `Lab5/` - префіксні вирази та додавання двійкових чисел за допомогою правил
- `README.md` - опис проєкту

## Висновки
Під час виконання роботи я ознайомилася з системою контролю версій Git та сервісом GitHub, створила публічний репозиторій і сформувала структуру навчального проєкту з окремими папками для кожної лабораторної роботи. Файли з фактами, шаблонами, правилами та функціями CLIPS були завантажені до репозиторію за допомогою GitHub Desktop: репозиторій було клоновано на комп'ютер, у нього скопійовано файли, після чого зміни зафіксовано одним комітом і відправлено на GitHub. Під час перенесення проєкту папки спочатку мали різні назви, що не відповідали структурі, описаній у README, тому їх було перейменовано на Lab1-Lab5 ще до коміту. Також у GitHub Desktop спочатку був відкритий інший репозиторій, тому новий репозиторій було додано через функцію клонування. Тепер усі результати лабораторних робіт зберігаються в одному місці разом з історією змін і доступні за посиланням
